# SMESTA Recruitment

Frontend recruitment workspace berbasis React + Vite dengan gaya visual yang mengikuti keluarga aplikasi `distributor-channel`.

## Menjalankan proyek

```bash
npm install
npm run dev
```

Klik tombol **Masuk ke SMESTA** pada halaman login untuk membuka demo. Sesi demo disimpan di `localStorage`.

## Fitur demo

- Login dan logout lokal
- Dashboard recruitment
- Pencarian dan filter kandidat
- Daftar lowongan
- Recruitment pipeline
- Jadwal interview
- Responsive sidebar dan layout mobile

Data saat ini bersifat mock dan dapat diganti dengan API backend.
